## 3. API list (all JSON `{ok, data, error}`, JSON error codes)

Auth (`/api/auth`)
- `GET  /csrf` – anonymous session + CSRF token
- `POST /login` `{role, identifier, password, remember}`
- `POST /logout`
- `GET  /session` – current user/profile, idle + server time
- `POST /heartbeat` – extend session

Common (`/api/common`)
- `GET /me`, `PATCH /me/contact`, `POST /me/photo`, `POST /me/password`
- `GET /notifications`, `POST /notifications/read-all`, `POST /notifications/<id>/read`
- `GET /search?q=` – command palette (pages, subjects, assignments, announcements)
- `GET /campus-images`
- `GET /files/assignment/<id>` / `GET /files/submission/<id>` – authorized downloads

Student (`/api/student`)
- `GET /overview`, `GET /attendance?from&to&page`, `GET /timetable`
- `GET /assignments`, `POST /assignments/<id>/submit` (multipart)
- `GET /announcements`, `POST /announcements/read`
- `GET /schedule/today`, `GET /profile`, `PATCH /profile`

Professor (`/api/professor`)
- `GET /overview`, `GET /batches`, `GET /students?batch_id&low_attendance`
- `GET /attendance?batch_id&subject_id&date`, `POST /attendance`
- `GET|POST /assignments`, `PATCH|DELETE /assignments/<id>`, `POST /assignments/<id>/restore`
- `GET /assignments/<id>/submissions`, `POST /submissions/<id>/grade`
- `POST /assignments/<id>/extend`, `POST /assignments/<id>/remind`, `GET /assignments/<id>/download`
- `GET|POST /announcements`, `PATCH|DELETE /announcements/<id>`
- `GET /schedule/today`, `GET /profile`, `PATCH /profile`

## 4. Design tokens (defined in `static/css/tokens.css`)

- Palette: deep blue primary `#1c3f94` (light) / `#7ea8ff` (dark), saffron accent `#f0a202`, success, warning, danger; neutral surface scale.
- Spacing: 4/8/12/16/24/32/48/64. Radii: 6/10/16/24/999. Shadows 3 levels.
- Type: Inter (self-hosted fallback to system stack), scale 12→56 px, greeting 40–56 px.
- Motion: 150/200/300 ms, `cubic-bezier(.2,.7,.3,1)`; disabled heavy motion under `prefers-reduced-motion`.

## 5. Assumptions

1. **Database engine.** MySQL 8 is the primary target (`database/schema.sql`, `seed.sql`). This machine has no MySQL server and no running Docker daemon, so the app also ships a byte-for-byte equivalent SQLite adapter (`DB_ENGINE=sqlite`, the default) so the portal can be launched, tested and reviewed immediately. Switching to MySQL is one `.env` change; no application code changes. All SQL is written to run on both engines.
2. **Late attendance counts as attended** for percentage maths (`present + late` over `held`), which is the common JECRC-style rule.
3. **Semester.** Batches are Semester 1 (2026 batch, CSE AI & DevOps A/B and CSE Core A), so subjects are first-semester subjects and timetables run Monday–Saturday. "Today" is derived from the real weekday; Sunday shows a friendly "No classes today" empty state.
4. **Credentials.** Every demo account uses password `Jecrc@2026`; professors log in with `firstname.lastname`, students with roll number. Rate limit: 5 failures per identifier+IP in 15 min → 15 min lockout.
5. **Sessions are server-side** (DB table) with HttpOnly SameSite=Lax cookie, 30-minute idle timeout, warning at 25 minutes, 12-hour absolute life (7 days with "Remember me").
6. **Uploads** are stored in `instance/uploads` with randomized names and served only through authorized endpoints; allowlist pdf/png/jpg/docx/zip, 10 MB cap. Profile-photo crop is done client-side on a canvas and uploaded as JPEG.
7. **Device block** is enforced by CSS (≤1023px), JS resize listener and server-side mobile user-agent detection. The resize block is a DOM overlay, so no dashboard state is lost when the window is widened again.
8. **Charts** use Chart.js 4.4.3 vendored at `static/vendor/chart.umd.js`; they re-read CSS tokens and re-render on theme change.
9. **Deletes** of assignments/announcements are soft (`deleted_at`) so the "Undo" toast can restore them without data loss.
10. **Campus photos** ship as four original SVG illustrations under `static/img/campus/` because real JECRC photographs are not licensed in this workspace; dropping `.jpg/.webp` files into that folder automatically adds them to the slideshow (README documents this).
